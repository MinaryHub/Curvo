# SETUP — 소스별 설정 가이드

ProjectorWarp 는 콘텐츠를 받아 → 왜곡해서 → 프로젝터로 내보내는 도구입니다.
콘텐츠를 받는 방법은 두 가지입니다.

1. **내장 재생** — 파일을 앱에 직접 열어 재생 (준비할 것이 거의 없음, **권장**)
2. **화면 캡처** — 다른 프로그램의 창이나 모니터를 캡처 (그 프로그램을 캡처 가능한 형태로 띄워야 함)

먼저 1번으로 되는지 확인하고, 안 되는 경우(실시간 조작이 필요한 앱, 웹 콘텐츠 등)에만 2번을 쓰세요.

---

## 0. 디스플레이 배치 (공통)

1. Windows 설정 → 시스템 → 디스플레이 에서 프로젝터를 **확장 모드**로 연결합니다.
   (복제 모드는 워핑된 화면이 노트북 화면에도 그대로 나와 작업이 어렵습니다.)
2. 프로젝터 디스플레이의 해상도를 프로젝터 네이티브 해상도로 맞춥니다.
3. 프로젝터 본체의 키스톤/디지털 줌 보정은 **모두 끕니다**. 이중 보정은 화질을 떨어뜨립니다.
4. ProjectorWarp 의 [출력 대상] 에서 프로젝터 디스플레이(`\\.\DISPLAY2` 등)를 선택합니다.

> 소스와 출력이 같은 모니터이면 컨트롤 패널에 빨간 경고가 표시됩니다.
> 출력 창 자체는 `WDA_EXCLUDEFROMCAPTURE` 로 캡처에서 제외되므로 무한 반사는 발생하지 않지만,
> 작업 화면과 투사 화면이 겹쳐 조작이 어렵습니다.

---

## 1. 내장 재생 (권장)

[내장 재생] 탭에서 파일을 열면 끝입니다. 외부 프로그램을 띄우거나 창 크기를 맞출 필요가 없습니다.

### 동영상

1. [동영상 열기] → 파일 선택
2. 출력 모니터가 지정되어 있으면 바로 재생이 시작됩니다.
3. [반복] 을 켜면 상시 재생에 적합합니다. 음량은 [음량] 슬라이더로 조절합니다.

재생되지 않으면 MP4(H.264) 로 변환해 보세요. Windows 가 재생할 수 있는 코덱이면 그대로 재생됩니다.

### PPT

| 상황 | 방법 |
|---|---|
| 이 PC 에 PowerPoint 가 있음 | [슬라이드 열기] 에서 `.pptx` 를 그대로 선택 → 자동으로 이미지 변환 후 재생 |
| PowerPoint 가 없음 | 자료가 있는 PC 에서 [파일 → 내보내기 → PDF] 로 저장 → 그 PDF 를 선택 |
| 슬라이드가 이미 이미지 | 여러 장을 한 번에 선택 (파일명 순서로 정렬됨) |

- 변환은 파일을 열 때 **한 번만** 수행되고 결과가 캐시됩니다. 재생 중에는 PowerPoint 가 실행되지 않습니다.
- 애니메이션·화면 전환·삽입된 동영상은 정지 이미지로 바뀝니다. 애니메이션이 꼭 필요하면 아래 2번(창 캡처)을 쓰세요.
- 장 넘기기: 출력 창에서 `PgDn`/`PgUp`, 또는 컨트롤 패널의 [◀ 이전]/[다음 ▶].
- [자동 전환] 을 1초 이상으로 두면 무인 슬라이드쇼가 됩니다.

---

## 2. PowerPoint 창 캡처 (애니메이션이 필요할 때)

애니메이션·전환 효과·발표자 조작이 필요하면 실제 PowerPoint 슬라이드쇼를 캡처합니다.
기본 슬라이드쇼는 특정 디스플레이를 **전체화면으로 점유**하기 때문에, 두 가지 경로 중 하나를 선택합니다.

### 경로 A — 창 모드로 띄워 창 캡처 (권장)

1. PowerPoint → **슬라이드 쇼** 탭 → **슬라이드 쇼 설정**
2. **보기 형식** 에서 **웹 형식으로 진행(개인이 브라우징)** 선택 → 확인
3. `F5` 로 슬라이드 쇼 시작 → 전체화면이 아닌 **창** 으로 실행됩니다.
4. ProjectorWarp 에서 [창] 탭 → `PowerPoint` 버튼 또는 목록에서 해당 창 선택 → [캡처 시작]

장점: 프로젝터 디스플레이를 PowerPoint 가 점유하지 않아 작업이 편합니다.
단점: 발표자 도구를 쓸 수 없고, 창 테두리 안쪽만 캡처됩니다.

### 경로 B — 전체화면 슬라이드쇼 + 모니터 캡처

1. 프로젝터 외에 **보조 디스플레이가 하나 더 필요**합니다.
   물리 모니터가 없다면 가상 디스플레이 어댑터(HDMI 더미 플러그) 또는 가상 디스플레이 드라이버를 사용합니다.
2. PowerPoint → 슬라이드 쇼 → **모니터** 를 그 보조 디스플레이로 지정하고 전체화면으로 실행합니다.
3. ProjectorWarp 에서 [모니터 전체] 탭 → 슬라이드쇼가 떠 있는 디스플레이 선택 → [캡처 시작]
4. [출력 대상] 은 **프로젝터 디스플레이** 로 지정합니다. (소스 모니터와 반드시 달라야 합니다.)

장점: 발표자 도구, 애니메이션, 전체화면 레이아웃이 그대로 유지됩니다.

---

## 3. 동영상 플레이어 캡처 (내장 재생으로 안 되는 경우)

컨트롤 패널의 `플레이어` 버튼이 실행 중인 플레이어 창을 자동으로 찾습니다.

공통 권장 설정:

- **플레이어를 창 모드로** 두고 창 캡처를 사용합니다. 전체화면이 필요하면 보조 디스플레이에 전체화면으로 띄우고
  모니터 캡처를 사용하세요.
- 플레이어의 **화면 비율 유지 / 레터박스** 설정은 켜 두는 편이 좋습니다. 워핑은 캡처된 화면 전체를 대상으로 합니다.
- 플레이어 자체의 회전·확대 기능은 끄고, 기하 보정은 ProjectorWarp 에서만 합니다.

렌더러별 참고:

| 플레이어 | 권장 렌더러 | 비고 |
|---|---|---|
| PotPlayer | Direct3D 11 / EVR | 오버레이 계열 렌더러는 캡처 시 검은 화면이 될 수 있습니다. |
| VLC | Direct3D11 출력 | 도구 → 환경설정 → 비디오 → 출력 |
| MPC-HC | EVR-CP / MPC VR | Overlay Mixer 는 사용하지 마세요. |

> 검은 화면만 캡처된다면 렌더러를 Direct3D 11 계열로 바꿔 보세요.
> 그래도 검은 화면이면 DRM 보호 콘텐츠일 가능성이 높습니다(우회 불가).

---

## 4. 브라우저 / 기타 앱

- 브라우저는 창 캡처가 잘 동작합니다. 전체화면(`F11`)으로 두고 창 캡처를 걸면 UI 없이 콘텐츠만 나옵니다.
- 하드웨어 가속을 끈 앱은 캡처가 느려질 수 있습니다. 가급적 GPU 렌더링을 켜 두세요.
- Netflix 등 DRM 스트리밍은 검은 화면으로 캡처됩니다.

---

## 5. 출력 창 조작

| 상황 | 방법 |
|---|---|
| 프로젝터 화면 위에서 보정하기 | 출력 창에 포커스를 준 뒤 `F1` (편집 모드) |
| 전체화면에서 빠져나오기 | `Esc` (창 모드 ↔ 전체화면 전환) |
| 다른 창이 출력 위로 올라올 때 | 컨트롤 패널의 [항상 위] 체크 유지 |
| 출력만 끄기 | 컨트롤 패널 [출력 중지] |

## 6. 무인 운영 (전시/상시 투사)

사람이 조작하지 않아도 PC 를 켜면 투사가 시작되게 만드는 순서입니다.

> 무인 운영에는 **내장 재생이 훨씬 안정적입니다.** 캡처 대상 프로그램이 뜨기를 기다릴 필요가 없고,
> 창 제목이 바뀌어도 영향이 없습니다. 가능하면 동영상/슬라이드를 내장 재생으로 쓰세요.

1. 먼저 **정상적으로 한 번 맞춥니다** — 소스 선택 → 출력 모니터 선택 → 재생/캡처 시작 → 곡면 정렬.
2. **[8. 설정 저장 · 자동 시작]** 에서 [현재 설정 저장] 을 누릅니다.
   (보정값 + 캡처 소스 + 출력 모니터가 함께 저장됩니다.)
3. 다음 세 옵션을 켭니다.
   - `Windows 로그온 시 자동 실행`
   - `앱 시작 시 자동으로 출력·캡처 시작`
   - `컨트롤 패널을 최소화 상태로 시작`
4. 캡처 대상이 다른 프로그램(플레이어, PowerPoint)이라면 그 프로그램도 자동 실행되도록 설정하고,
   **재시도 시간**을 그 프로그램이 뜨는 데 걸리는 시간보다 넉넉하게 잡습니다(예: 120초).
5. 재부팅해서 확인합니다.

### 권장 조합

| 상황 | 설정 |
|---|---|
| 동영상 상시 재생 | **내장 재생 + [반복]** — 외부 플레이어 불필요, 재시도 시간도 필요 없음 |
| 슬라이드 상시 순환 | **내장 재생 + [자동 전환] 10~30초** |
| 애니메이션 있는 PPT | PowerPoint 슬라이드쇼를 보조 디스플레이에 띄우고 **모니터 전체** 캡처, 재시도 시간 120초 |
| 보조 디스플레이 전체화면 콘텐츠 | 소스를 **모니터 전체**로 지정 (창 제목에 의존하지 않아 안정적) |
| 발표용(사람이 조작) | 자동 실행만 켜고 자동 시작은 끔 — 상황에 맞게 소스를 골라 쓰기 |

> 창 캡처는 창 제목/프로세스 이름으로 대상을 다시 찾습니다. 제목이 매번 바뀌는 프로그램(파일명이 제목에 들어가는 등)은
> 모니터 전체 캡처가 더 안정적입니다.

Windows 자동 로그온이 꺼져 있으면 로그온 전까지는 실행되지 않습니다(Run 키는 사용자 로그온 시 동작).
로그온 없이 부팅만으로 실행해야 한다면 작업 스케줄러에 "시스템 시작 시" 트리거로 등록하세요.

## 7. 문제 해결

| 증상 | 원인 / 조치 |
|---|---|
| "Windows.Graphics.Capture 를 사용할 수 없습니다" | Windows 10 1903 미만입니다. OS 업데이트가 필요합니다. |
| 캡처 화면이 검은색 | DRM 보호 콘텐츠 / 오버레이 렌더러 / 최소화된 창 |
| 노란 테두리가 소스 창에 생김 | Windows 10 의 캡처 표시입니다. Windows 11 에서는 자동으로 제거됩니다. |
| 출력이 프로젝터가 아닌 곳에 뜸 | [출력 대상] 모니터를 다시 선택하고 [출력 시작] |
| 화면이 무한 반사됨 | 출력 창 캡처 제외에 실패한 경우입니다. 소스를 창 캡처로 바꾸거나 다른 모니터를 캡처하세요. |
| 소스 창 크기를 바꾸면 화면이 늘어남 | 정상입니다. 제어점은 정규화 좌표라 기하 형상은 유지되고, 내용만 새 해상도로 다시 채워집니다. |
| 내장 재생에서 동영상이 안 열림 | 코덱 문제입니다. MP4(H.264) 로 변환하세요. DRM 보호 파일은 재생할 수 없습니다. |
| PPT 를 열 때 오류가 남 | 이 PC 에 PowerPoint 가 없거나 파일이 손상된 경우입니다. PDF 로 내보내 사용하세요. |
| 슬라이드 변환이 오래 걸림 | 첫 변환만 느립니다. 이후에는 캐시에서 즉시 로드됩니다. |
| 자동 시작이 동작하지 않음 | 상태 표시줄 메시지를 확인하세요. 대상 창을 못 찾은 경우가 대부분이며, 재시도 시간을 늘리거나 모니터 전체 캡처로 바꾸면 해결됩니다. |
| 자동 실행 등록이 실패함 | 그룹 정책으로 Run 키가 잠긴 환경입니다. 시작 폴더(`shell:startup`)에 바로 가기를 만들고 인자에 `--autostart` 를 넣으세요. |
