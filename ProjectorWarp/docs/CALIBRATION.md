# CALIBRATION — 곡면 정렬 실무 절차

곡면(원통형 벽, 기둥, 아치)에 투사할 때 직선을 직선으로 만드는 순서입니다.
**물리 → 코너 핀 → 곡면 → 미세 조정** 순서를 지키는 것이 핵심입니다.
순서를 뒤집으면 앞 단계 오차를 뒷 단계에서 계속 되잡게 됩니다.

---

## 0. 준비 (물리 정렬이 먼저)

디지털 보정은 픽셀을 늘이고 줄이는 작업이라, 물리 정렬이 나쁠수록 해상도 손실이 커집니다.

1. 프로젝터를 벽면에 가능한 한 **정면·수평**으로 설치합니다. 렌즈 중심이 투사면 중심을 향하게 합니다.
2. 프로젝터의 **키스톤 보정·디지털 줌은 모두 끕니다.** 렌즈 시프트가 있다면 그것으로 위치를 맞춥니다.
3. 초점은 곡면의 **중간 깊이** 에 맞춥니다. 곡면은 위치마다 투사 거리가 달라 완전한 전역 초점은 나오지 않습니다.
4. 조명을 낮추고 화이트 풀필드(`F2` → 화이트)로 밝기·색 얼룩을 먼저 확인합니다.

---

## 1. 테스트 패턴 띄우기

1. 소스와 출력을 연결한 뒤 출력 창에 포커스를 주고 `F1` 로 편집 모드를 켭니다.
2. `F2` 를 눌러 **격자** 패턴을 선택합니다.
3. 필요하면 `F3`(참조 그리드), `F4`(대각선)를 켭니다.
   - **격자 패턴**: 워핑을 따라 함께 휘어지는 패턴 → 실제 벽면에서 직선인지 판단용
   - **참조 그리드 / 대각선**: 화면 좌표에 고정된 기준선 → 대칭·중심 확인용

> 격자는 워핑 메시에 실려 함께 휘고, 참조 그리드는 출력 화면에 고정됩니다. 두 선의 관계를 보며 조정합니다.

---

## 2. 코너 핀으로 투사 영역 잡기

1. 컨트롤 패널에서 **[코너 핀 / 키스톤 사용]** 을 켭니다. 초록색 사각형과 4개 핸들이 나타납니다.
2. 각 모서리를 드래그해 **투사하고 싶은 영역의 네 귀퉁이**에 맞춥니다.
   - 곡면이라도 이 단계에서는 "대략 이 범위" 정도면 충분합니다.
   - 벽면의 물리적 기준(몰딩, 바닥선, 기둥 경계)에 맞추면 이후가 편합니다.
3. 미세 조정은 핸들을 클릭해 선택한 뒤 **방향키**(1px) / **Shift+방향키**(10px)를 사용합니다.

이 단계가 끝나면 화면 **가장자리**는 맞고 **가운데가 휘어 보이는** 상태가 됩니다. 정상입니다.

---

## 3. 베지어 곡면으로 휨 잡기

1. **[베지어 곡면 워핑 사용]** 이 켜져 있는지 확인합니다(기본 켜짐).
2. 제어점 격자 크기를 정합니다.

   | 투사면 | 권장 격자 |
   |---|---|
   | 완만한 원통형 벽 | 3×3 또는 4×4 |
   | 일반 곡면 벽 (기본) | 4×4 |
   | 기둥·아치처럼 굴곡이 두 방향인 면 | 5×5 |
   | 국소적으로 튀어나온 구조물 | 6×6 |

   > 격자를 **늘릴 때는 형상이 그대로 보존**됩니다(차수 상승). 4×4 로 대략 잡고 필요한 곳만 5×5·6×6 으로
   > 올려 세밀하게 다듬는 순서를 권합니다. 반대로 줄이면 형상이 근사되므로 되도록 줄이지 마세요.

3. **가장자리 → 안쪽** 순서로 제어점을 옮깁니다.
   - 먼저 상·하·좌·우 **변의 중간 제어점**을 움직여 변이 벽면에서 직선이 되게 합니다.
   - 그다음 **모서리 근처**, 마지막으로 **안쪽 제어점**을 다듬습니다.
   - 베지어는 제어점이 곡면을 "끌어당기는" 방식이라, 실제 이동량보다 화면 변화가 작습니다. 조금씩 옮기세요.
4. 격자 선이 벽면에서 직선으로 보이면 완료입니다. 정면이 아닌 **관객이 실제로 볼 위치에서** 확인하세요.

### 테셀레이션

- 기본 64×64 로 충분합니다. 곡률이 심해 격자선이 각져 보이면 96~128 로 올립니다.
- 낮은 사양 GPU 에서 프레임이 떨어지면 32~48 로 내립니다. 화질보다 부드러움이 중요할 때만 조정하세요.

---

## 4. 마스킹 (선택)

투사하면 안 되는 영역(문틀, 배관, 창문)을 가립니다.

1. **[블랙 마스크 사용]** 체크 → **[마스크 추가]**(또는 출력 창에서 `M`)
2. 편집 모드에서 꼭짓점을 드래그해 가릴 영역에 맞춥니다.
3. 꼭짓점이 남으면 **오른쪽 클릭**으로 삭제합니다(최소 3개 유지).
4. 마스크 전체 삭제는 `Del` 또는 [선택 마스크 삭제].

마스크는 워핑 이후 화면 좌표에 그려지므로, 워핑을 다시 바꾸면 마스크 위치도 다시 확인해야 합니다.
**워핑을 먼저 확정하고 마스킹을 마지막에** 하세요.

---

## 5. 색상 보정 (선택)

1. `F2` 로 **화이트 풀필드**를 띄웁니다.
2. **[색상 보정 사용]** 을 켜고 조정합니다.
   - **밝기**: 전체 광량. 다른 프로젝터와 밝기를 맞출 때 사용합니다.
   - **대비**: 어두운 실내에서 너무 강하면 0.9 정도로 낮춥니다.
   - **감마**: 중간톤. 곡면 가장자리가 어둡게 느껴지면 1.1~1.3 으로 올립니다.
3. 컬러바 패턴으로 색 재현을 확인합니다.

---

## 6. 엣지 블렌딩 (멀티 프로젝터)

두 대 이상으로 넓은 곡면을 이어 붙일 때 겹치는 구간을 부드럽게 만듭니다.

1. 두 프로젝터의 투사 영역이 **10~20% 정도 겹치도록** 물리적으로 배치합니다.
2. 각 인스턴스에서 **[엣지 블렌딩 사용]** 을 켭니다.
3. 겹치는 쪽 변의 폭을 **양쪽 동일하게** 설정합니다.
   (예: 왼쪽 프로젝터의 `우` = 0.15, 오른쪽 프로젝터의 `좌` = 0.15)
4. **감마**를 조정해 겹침부의 밝기 단차를 없앱니다. 일반적으로 2.2 부근에서 시작합니다.
   - 겹침부가 **밝으면** 감마를 올립니다.
   - 겹침부가 **어두우면** 감마를 내립니다.
5. 화이트 풀필드로 확인하고, 격자 패턴으로 두 화면의 격자선이 겹침부에서 일치하는지 확인합니다.

---

## 7. 저장과 재현

1. 정렬이 끝나면 `Ctrl+S` 로 프리셋을 저장합니다. 장소·용도별로 파일을 나눠 두세요.
2. 앱 종료 시 마지막 상태가 자동 저장되어 다음 실행에 복원됩니다.
3. 프리셋에는 캡처 소스(창 제목/프로세스, 모니터 이름)와 출력 모니터도 함께 기록되어,
   같은 환경이면 불러오는 것만으로 다시 연결됩니다.

> 프로젝터를 옮기거나 해상도를 바꾸면 기하 정렬을 다시 해야 합니다.
> 제어점은 정규화 좌표라 **해상도가 바뀌어도 형상은 유지**되지만, 물리적 위치가 바뀌면 의미가 달라집니다.

## 현장 체크리스트

- [ ] 프로젝터 키스톤/디지털 줌 끔, 확장 모드 연결, 네이티브 해상도 설정
- [ ] 출력 대상 = 프로젝터 디스플레이, 소스와 다른 모니터
- [ ] 화이트 풀필드로 초점·밝기 얼룩 확인
- [ ] 코너 핀으로 투사 영역 확정
- [ ] 격자 패턴으로 곡면 제어점 조정 (가장자리 → 안쪽)
- [ ] 관객 시점에서 직선 확인
- [ ] 마스킹 → 색상 보정 → 엣지 블렌딩 순서로 마무리
- [ ] `Ctrl+S` 로 프리셋 저장
- [ ] `F1` 로 편집 모드 끄고 `F2` 로 패턴을 [없음] 으로 되돌린 뒤 실제 콘텐츠 확인
